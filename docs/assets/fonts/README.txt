Fonts in this folder, all under the SIL Open Font License 1.1:

  JuliaMono-subset.woff2    JuliaMono by cormullion (github.com/cormullion/juliamono),
                            reduced to the characters the books use.
  Hieroglyphs-subset.woff2  Noto Sans Egyptian Hieroglyphs (Google), four glyphs.
  UncialAntiqua.woff2       Uncial Antiqua by Astigmatic.
  EBGaramond*.woff2         EB Garamond by Georg Duffner and Octavio Pardo.

If a book gains characters the subset lacks, the page falls back to the
reader's own monospace font for those characters.
